# DOM selector

- document.getElementById();
  - It will target only the first matching Node
- document.getElementByClassName();
  - It will target all the matching Niodes
  - it wilkl return an html collection
- document.getElementbyTagName();   
  - It will target all the matching Niodes
  - it wilkl return an html collection (Array like structure) 
- documemt.getElementByName();
  - It will target the element based on name attribute's values
  - it will return a collection.

- document.querySelector();
  - it can target based on id , class , tagname.
  - it will return only the first matching element even, its is id class and tagName.
- document.querySelectorAll();
  - it can target based on id , class , tagName.
  - it will return all the matching element even its , id , class and tag name.
